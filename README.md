# Storm Summit: Save the Campaign

A 40-second mobile-first browser game promoting [Plario](https://plario.io) at Web Summit Lisbon 2026.

- Single self-contained `index.html`: no dependencies, no build step, no tracking.
- Hosted at `storm.plario.io`.

## Deploy (Vercel)
New Project → import this repo → Framework preset **Other**, no build command, output directory `.` → add the domain `storm.plario.io` → DNS: `CNAME storm cname.vercel-dns.com`.

## Edit
Everything (styles, game code, inline logo) lives in `index.html`. Open it in a browser to test locally.
